# Pinry (LazyCat LPK)

Self-hosted image board for saving, tagging and sharing pictures.

- Upstream: https://github.com/pinry/pinry
- Image: `getpinry/pinry:2.1.13` (mirror mode, digest-matched)
- License: BSD-2-Clause (full text in `content/licenses/LICENSE.md`)
- Containers: single (SQLite under /data)

## Notes
- No pre-seeded account; first user registers via the UI (`ALLOW_NEW_REGISTRATIONS = True`).
- SECRET_KEY is generated by the image on first start into /data/local_settings.py.
- Not yet verified on a real device.
